## 演示入口

在 `apps/console` 安装锁定依赖（`npm ci`），启动 `npm run dev`，浏览器访问 `/demo`。首页也提供“观看竞赛演示”入口。不需要 Python 后端、账户、地图服务或云资源。生产部署应提供 SPA 路由回退。

确认示例工单后，播放三分钟情景。可以暂停、拖动时间轴、点击章节或已发生事件进行重拍。录制模式隐藏控制栏，Escape 恢复；重置后回到未确认状态。影片中的模型、地点、动画和通信状态为演示素材。算法章节读取冻结的规划与独立校验输出，使用对应的 ENU 场景图；虚构滨水城市场景不作为算法避障依据。
