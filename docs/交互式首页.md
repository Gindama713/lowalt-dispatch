# AERIS 交互式三维首页

首页继续使用队友的 LandingPage、导航和日夜主题，在原 3D 占位区接入真实资源。

- CR30：直接引用 references/rea-city-flight/asset/out/cr30.glb。按模型原有 explodeDir、explodeDist、stagger 数据分解与反向复原。
- 城市：直接引用 references/rea-city-flight/map-nav/map/city-world.js 及其依赖。该文件为仓库中最新的 REA 提取场景，不是真实地理数据。
- 支持分解滑杆、自动环绕、拖动旋转、缩放、视角重置、扫描与全屏。
- 用户选择减少动态效果时停止自动运动，离屏和后台标签暂停渲染；退出页面释放几何体、纹理、控制器与解码器。
- 原有任务、规划、地图、设备、身份与后端业务代码保持原样。

## 本地启动

在 apps/console 执行 npm ci 和 npm run dev:all，打开 http://127.0.0.1:5174/。
后端 Python 依赖和环境初始化按该目录原 README 操作。

## HTML 交付

在 apps/console 执行 npm run export:home，生成 dist/home-preview/AERIS-home.html。
该单文件内嵌 Three.js、CR30、Draco 解码器、城市源码及字体，可直接在现代浏览器打开。
此文件供首页交互审阅；业务入口会打开本机 5174 端口的完整项目。
完整功能使用原项目或 npm run build 生成的 dist，不能用独立首页替代后端。

## 检查

npm run build
npm run export:home
npx playwright test tests/hero.spec.ts tests/home-export.spec.ts tests/portal.spec.ts tests/theme.spec.ts

GitHub Actions 的 AERIS homepage preview 流程会输出单文件 HTML、完整前端构建与浏览器截图。
测试通过与否以 Actions 实际结果为准。
