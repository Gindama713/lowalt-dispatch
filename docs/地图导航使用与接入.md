# 飞行导航 · 本地参考与演练

入口：空域态势或设备与遥测的地图工具栏“导航”，或地图下方“飞行导航”。帮助中心也提供入口。已有定位、地图图层、二维/三维、公开DEM、天气、地形实验、事件流和Agent功能保留。

## 第一次体验

1. 运行 `apps/console` 的 `npm run dev:all`，登录后进入“空域态势”，打开“飞行导航”。
2. 在“航线与方案”查看演练基线；点击“计算场景方案”，后端调用仓库几何A*，使用30/60m栅格膨胀参数计算固定场景的两条路线。
3. 选择参考方案，其他方案可叠加对比。蓝线为当前参考、紫色虚线为对比，青绿为实际收到的WGS84轨迹或演练已走航段。航程为水平长度，估时按明确列出的演练巡航速度计算。
4. 点击“开始航线演练 → 确认启用参考”。地图出现航点卡片，导航区显示剩余航程、偏航、估时与可用的高度差。演练位置沿所选路线插值，与原演示仪表独立。
5. “航线全览”解除跟随；“恢复跟随”重新锁定导航位置。手动拖动、旋转、缩放会解除跟随，系统不会抢回视图。跟随模式按起始、巡航、终段和航点动作调整比例尺；2D保持北向上，3D使用航向视角。启用减少动态效果时取消相机过渡动画。
6. 接近明显转向或有高度变化的航点时，卡片显示动作聚焦；高度剖面只有在全部航点有统一基准的高度时才显示。当前地图线为水平投影，不能当作真实空间走廊或垂直净空。
7. “结束参考引导”只关闭显示和提示，不影响飞控任务。切换地形实验或终端地图会暂停参考引导，避免把新导航路线与原场景航迹混在一起。

场景路线全部来自固定ENU场景，不能用于地图上任意真实地点。30/60m是障碍栅格膨胀参数，不是实测最小净空；所有场景限制区保守静态避让。两条路线可能相同，也可能某个参数下无解；无解明确显示，不移动端点。未加入风、机型、动态空域、能量和备降硬约束，因此不能称为“最低风险/最省电”或当作已批准飞行计划。

## 真实遥测与无航线观察

“设备与遥测”读取既有 `/api/telemetry/stream`。未导入航线时可“开始自由观察”，显示现有遥测的低电量提示及WGS84轨迹；没有目的地时不计算航点或剩余航程。

有航线时，实时引导要求以下条件同时成立：

- 遥测状态为实时，位置可用；超过现有5秒过期阈值暂停计算，不把最后一帧当实时位置。
- 航线与遥测坐标系一致。NED的水平坐标转换为ENU：东=y，北=x；高度只读取显式高度与基准，不把z自动当海拔。
- `task_id` 与 `plan_version` 均存在且完全一致；`is_simulated`也一致。

任一条件不满足，参考航线仍可查看，航点距离、ETA和偏航暂停；不会自动匹配最近的一条路线。恢复匹配后恢复计算。来源或参考航线内容变化要求重新确认启用。

航点进度来自最近航段的几何投影，不是 PX4 当前任务航点索引。在回环、交叉或往返重叠航线中可能无法唯一确定航段；不能用该显示替代飞控执行进度。

ENU/NED遥测与匹配航线在局部轨迹图中显示。没有地理标定的局部航线不套用演示城区锚点，也不产生真实地图位置。BFF已有任务航线可从任务详情带入；从本地场景API返回的ENU投影继续明确标记为合成场景。

## 坐标与导入协议

当前底图为CARTO/OSM及Esri，位置契约为WGS84。无需GCJ02偏移转换；不能把不明来源的高德/百度坐标声明为WGS84。地图显示经纬度使用Web Mercator投影，纬度限制±85.0511°。将来接高德时，应另建地图适配器，只在视图边界转换，原始任务、遥测及导出保留原始坐标系。

导航区可下载示例JSON。单次文件≤1MB，包含1–8条航线，每条2–1000个航点。当前浏览器最多保留8条导入记录，仅在本次页面会话内存在；导航阈值等偏好另保存在 `aeris.navigation.preferences`。整个文件校验通过后才应用，错误文件不部分覆盖旧路线。

```json
{
  "id": "inspection-route-v1",
  "title": "巡检参考航线",
  "source": "规划服务名称 / 数据修订版本",
  "frame": "WGS84",
  "altitude_ref": "rel_takeoff",
  "is_simulated": true,
  "task_id": "actual-task-id",
  "plan_version": "v1",
  "waypoints": [
    { "x": 121.4737, "y": 31.2304, "altitude": 100, "label": "起点" },
    { "x": 121.4767, "y": 31.2334, "altitude": 120, "label": "巡检点" },
    { "x": 121.4797, "y": 31.2314, "altitude": 100, "label": "终点" }
  ]
}
```

- WGS84：x为经度、y为纬度；ENU：x为东向米数、y为北向米数；NED：x为北向米数、y为东向米数。当前仅允许100km局部区域内的航线。
- 提供高度时必须声明 `amsl`（海拔）、`agl`（离地）或 `rel_takeoff`（相对起飞点），单位米。高度差只有航线与遥测基准相同时计算；不推测地面标高或起飞点海拔。
- `is_simulated`是数据声明，不是系统对真实性的认证。下载的示例必须替换成实际数据，不能当作真实任务。
- 多方案用 `{ "routes": [ ... ] }` 包装，同一文件id不得重复。不同坐标系/不同起点的路线只供查看，不据此判断优劣。
- 实时轨迹按时间、来源、任务与版本分段，断流超过5秒不连成直线；只保留既有遥测缓存窗口内的轨迹。

## 提示、语音和快捷操作

- 默认偏航阈值80m、低电量25%、动作聚焦250m；可在导航设置修改。≤15%电量为持续紧急提示，不能“已知悉”隐藏；常规提示可知悉，指标恢复后再次触发会重新出现。
- 有效数据下还提示同基准目标高度差，以及演练场景中前方航段与地形变化范围的平面重叠。地形提示不是碰撞判定，也不会自动改线。
- 切换导航分页或收起面板仍保留未知悉的告警摘要。事件流记录提示首次出现，不按每帧重复刷屏。导出导航记录包含来源、时间、路线、计算结果、阻塞原因与提示，始终标记 `dispatch_enabled: false`。
- 播报默认关闭，可选择“仅安全提示 / 安全与航点动作”。使用浏览器SpeechSynthesis，不接额外模型；系统中文语音可用性决定效果，文字始终保留。
- “语音输入”采用浏览器SpeechRecognition，可能使用浏览器的在线识别服务。只在点击后请求麦克风权限，识别结果先填入文本框；必须核对后点击“执行视图操作”。未支持/拒绝权限/网络失败均可继续手动输入。
- 快捷文本支持：全览、跟随、静音、暂停演练、继续演练、打开助手。悬停、升降高、返航等飞行指令不在此入口执行，继续使用已有审核与执行回执链路。

## 飞前核对与报告的落实

参考团队提供的《组员可看懂的无人机知识》（2026年11月内部学习材料），并于2026-11-16读取核对了中国政府网[《无人驾驶航空器飞行管理暂行条例》（国令第761号）原文](https://www.gov.cn/zhengce/content/202306/content_6888799.htm)。核对的重点为第十二条责任保险、第十九至二十条空域与临时管制、第二十六至三十一条申请及例外、第三十二条飞行行为规范。这是对该原文的核对，不表示已完成所有后续修订和地方规则的穷尽检索。

报告是学习资料，不是系统可执行的法规数据库。报告提及的2026年新法、新国标、过渡期、处罚金额、审批时限等，本次未逐条完成有效版本核验，因此未硬编码为自动判定规则。真实作业仍需按适用的 CCAR-92、运行类别、当地公告和主管部门要求核实。

导航工作区新增“飞前核对”，流程为：

1. 选择航线，再填写航空器分类、运行性质、计划起止时间。机型分类人工核实，不单凭重量推断。
2. 从 [UOM](https://uom.caac.gov.cn/)、政府与空管发布信息核对空域与临时限制。填写发布源/版本、覆盖范围与高度基准、实际核对时刻、资料有效起止时刻。系统仅检查这些人工记录是否完整、时间顺序及是否覆盖计划时段；不验证发布源真实性，也不自动完成空间包含关系或审批审查。
3. 展开八项清单，记录登记与运行识别、人员与运营资质、责任保险、官方空域、申请/批准/起飞前确认、机体与链路、环境、载荷及特殊作业。允许“不适用”的项目必须说明依据；官方空域、机体和现场环境等基础项不提供一键豁免。
4. 点击“保存本次核对”，即使资料不齐也能保存待办记录。结果显示待复核项，永远不输出“已批准/可以飞”。全部填写后仍为人工资料记录，`authorization: not_determined`、`dispatch_enabled: false`。
5. 导出JSON保留核对内容、航线完整范围指纹、任务/版本、模式、UTC时刻和本机时区。导航记录导出也带入已保存核对快照。记录仅在当前页面会话内保留，不同步服务器；刷新前需导出。未保存的修改不进入导出。

| 报告涉及的问题 | 界面的处理 |
| --- | --- |
| 低于120m就可以飞？ | 不自动放行；要求官方空域、临时管制和运行条件核对。 |
| 海拔、相对起飞高度与真高混淆 | 航点/遥测保留高度基准；没有完整AGL时明确提示无法据此判断真高限制。AGL声明本身仍不代表已实测或合法。 |
| 厂商解禁、地图无红区 | 明示不能替代官方许可；公开底图与构造场景禁限区不是法定空域。 |
| 应急、医疗、物流、超视距、中继、集群 | 在运行性质与特殊作业清单说明，按具体条件人工核实；没有自动豁免或一键解锁。 |
| 夜间、现场天气与地面风险 | 单独核对灯光、能见度、风雨、人群与线缆；界面夜间模式不等于夜间飞行资格。 |
| 资料失效或任务变化 | 每30秒刷新时效提示；航线内容、任务版本或模式改变即提示重新核对保存。临时公告仍需现场主动查询。 |
| 异常与事故处置 | 保留人工接管、适用报告义务与证据提示，不把所有事故简化为同一24小时时限。 |

飞前资料未齐不会阻断被动观察和紧急提示，也不会自动触发返航、悬停或改线。已有任务审核是软件操作流程，不代表取得行政许可；本次未改变飞控或原有执行授权逻辑。真实飞行前的法规适用性、资料真伪、空间覆盖、运行识别合规、保险/资质与现场安全仍由作业负责人复核。不要在备注中填写密码、完整个人证件号或复制机密批文。

## 七类空域参考图层

按队伍提供的参考站分类文字提供以下七类，不宣称已复制或接入该站底层数据：

| 分类 | 颜色 | 阅读方式 |
| --- | --- | --- |
| 适飞空域参考 | 青绿 | 不等于任何机型、任何运行方式都允许飞行。 |
| 内部管制区域参考 | 紫 | 团队/场地内部管控与法定管制空域分开识别。 |
| 禁飞区 | 红 | 核对原发布主体、范围与适用条件。 |
| 限高区 | 灰蓝 | 显示提供的高度上限与AGL/AMSL/相对起飞点基准；缺失时不推测。 |
| 授权区 | 蓝 | 厂商授权参考，解禁不等于行政许可。 |
| 加强警示区 | 橙 | 显示来源的风险说明与要求。 |
| 警示区 | 黄 | 参考提醒，不能反推区外一定可飞。 |

地图右下角“空域图例”可展开/收起；导航工作区“空域图层”提供分类开关、搜索、区域列表、详情、定位、导入与导出。点击地图上的区域边界内或名称标识会打开对应详情；区域重叠时也可在列表选择。计数按**当前会话载入总数**计算，不冒充当前视野或全国统计。隐藏分类只改变显示，不改变真实限制或原规划器行为。图层全部以水平投影显示，不计算空域三维穿越、合法性或碰撞。

没有预装法定全国禁限飞边界，也没有自动抓取 UOM、国家地图官网或天地图后台。地图仍是 MapLibre 上的 CARTO Positron 日间街道或 Esri 卫星影像，不把底图涂成纯黑。

全国范围另有一层大疆 FlySafe 厂商地理围栏参考（PyPI 包 `dji-geo`，不内嵌其源码；该上游仓库在 2026-11-20 的 0.1.0 发布没有 LICENSE 文件）。查询范围是文档中的中国矩形（西 73.5°、南 18.0°、东 135.1°、北 53.6°），不是法定国界。`dji-geo` 会把每个分块再切开并去重。失败的分块不补造几何；只要有分块失败，界面写明「本次全国刷新不完整」，不能把这层说成官方中国全图。之后整次刷新失败时，地图继续显示上次成功写入本地缓存的全国围栏。这层默认打开，跟「限制区」开关走，不因换工单、平移缩放或规划刷新失败而被清掉，也不会把镜头拉去包住全国。图上这层围栏不论警示、加强警示或限高，都是同一种红色。它不写入航线约束快照，因此不受规划快照 100 个区域的上限影响，也不参与硬避让。

设置真实起终点后，规划仍只按起终点外扩约 800 m 查询 FlySafe，并绑定为约束快照。只有禁飞和法规限制类进入硬避让。镜头对准起终点以及落在该航线范围外扩约 0.3° 内的规划围栏顶点。图例和空域面板写明这是厂商地理围栏参考，不是法定空域，也不是飞行批准。规划查询瞬时失败时，仍保留上次成功的规划围栏。没有上次成功几何时，失败或 0 个区域仍是未知，不是放行。手动导入和演练走廊是附加对照，隐藏分类不会取消避让。空数据状态不能理解成没有飞行限制。下载示例使用手工构造区域，始终标记演练，不会自动载入真实地图。本地缓存目录默认是 `logs/flysafe-national/`（可用 `AERIS_FLYSAFE_CACHE_DIR` 改），不提交进仓库。`AERIS_FLYSAFE_LIVE=0` 时不访问大疆网络。

导入协议为扩展GeoJSON，文件≤5MB，1–100个区域、总顶点≤20000，Polygon/MultiPolygon闭合轮廓；必须显式声明 `coordinate_system: WGS84`。不接受GCJ02、含糊的crs、跨180°经线轮廓、零面积或未闭合数据。对复杂多边形拓扑未进行GIS级认证；不得据此做空间合规结论。整个文件校验通过后替换本会话图层，错误时原数据不变。

```json
{
  "type": "FeatureCollection",
  "coordinate_system": "WGS84",
  "features": [{
    "type": "Feature",
    "geometry": {
      "type": "Polygon",
      "coordinates": [[[121.47,31.23],[121.48,31.23],[121.48,31.24],[121.47,31.24],[121.47,31.23]]]
    },
    "properties": {
      "id": "example-only",
      "name": "构造示例区域 · 非真实禁限飞数据",
      "kind": "warning",
      "source_kind": "team",
      "source": "手工构造教学示例",
      "source_ref": "示例，不是公告",
      "updated_at": "2026-11-16T00:00:00Z",
      "effective_from": null,
      "effective_until": null,
      "is_simulated": true,
      "max_height_m": null,
      "altitude_ref": null,
      "description": "仅供验证显示与导入流程。"
    }
  }]
}
```

`kind`可选 `suitable/internal/restricted/altitude/authorization/enhanced_warning/warning`；`source_kind`可选`official/manufacturer/team`，均为文件提供者的声明，不是系统认证。有效时刻需带时区，缺失时显示“时效待核实”，过期数据保留提示而非悄悄移除。`max_height_m`存在时必须有高度基准。导出保留区域几何与来源元数据，导航证据同时记录已载入区域和可见分类。网页中所有本机时间按本机时区显示。

要接入真实全国范围，还需要队伍提供具有使用授权、可更新的区域数据文件或正式接口，并核对坐标、时间、用途和覆盖范围；厂商与官方来源不能互相替代。

- `services/assistant/navigation.py` 与BFF `/api/assistant/navigation/candidates`：有登录/角色保护的静态场景A*。单并发限制和固定规模，沿用助手审计。
- 浏览器：`npm test`；导航单测与流程：`npx playwright test tests/navigation-math.spec.ts tests/navigation.spec.ts`。
- 后端：`python -m pytest services/assistant/tests/test_navigation.py`，同时保留已有任务/身份/助手回归。
