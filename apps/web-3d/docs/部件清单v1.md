## 1. 约定（定稿，不许改）

- **机体坐标系**：原点 = 机身壳体包围盒几何中心；**x 前、y 左、z 上**；右手系；单位 mm。所有 `geometry`/`pivot` 坐标均为**展开飞行态、静止姿态**下的机体坐标。
- 导出 GLB 时 Blender 自动转 glTF 的 Y-up：three.js 中 `X=机体x(前)`，`Y=机体z(上)`，`Z=−机体y`；GLB 单位为米。
- **命名冻结**：id 定稿后禁止改名；新增细分件只能追加新 id（如 *_sub_x），不得重命名既有 id。 共 **69 个唯一实例 id、28 类部件**（成组件逐个编号：`_fl/_fr/_rl/_rr` = 左前/右前/左后/右后，`_l/_r` = 左/右）。
- 每个部件写死五项：**尺寸 `dims_mm`、材质 `material`、可动 `movable`、转轴 `pivot{pos,axis,type,range}`、浮签 `tooltip`**；另有 `explode`（爆炸位移）、`fx`（灯效/展开时序）、`source`（来源/估算标记）、`parent`（运动学父子）、`contacts`（允许接触的安装面）。
- 来源标记：**官方** = DJI 官网规格页/用户手册原值；**反推** = 由官方值计算得到；**估算** = 官方未公开，按图纸比例/工程惯例估计（写明依据）；**项目自定义** = 非 M350 原装。
