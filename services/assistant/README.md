# AERIS 调度助手：本地服务与华为云模型接入

前端位于 `apps/console/src/assistant/`，后端位于本目录。此服务支持独立控制台演示，保留现有 M2/M3/PX4 接口。

2026-11-11：同一服务现已挂载 `/api/dispatch/*` 本地合成任务链路。顶部「本地任务联调」可调用真实 M3/M2/独立校验及 M4 FakeExecutor，支持直连或 MQTT；操作见 [`services/api/README.md`](../api/README.md)。这与下面仅问答/草稿的助手工具是两个明确入口，不会把对话中的任务自动下发。

## 已实现什么

| 能力 | 实际行为 | 适用范围 |
| --- | --- | --- |
| 项目文档问答 | 检索仓库指定 Markdown 文档，展开对应章节的原文、行号与内容版本 | 适用于项目规则、接口语义与启动说明 |
| 态势问答 | 读取当前快照，显示电量、速度等，支持地图定位和展开仪表 | 来源为浏览器演示或最新 M4 遥测快照 |
| 自然语言建任务 | 多轮补起终点与载荷，编辑任务卡，明确确认后存入任务空间 | 不猜未知地点坐标；不下发 |
| 几何路线预览 | 调用仓库 `planner.astar.plan`，计算并在地图叠加独立路线 | 全部场景限制区保守视为静态障碍；能量/备降/动态地形未校验 |
| 异常辅助分析 | 对DEM变化包围框与基线逐线段求交，区分剩余/已过航段，定位区域 | 不是碰撞或安全结论；缺能量和垂向净空校验 |
| 记录解释 | 汇总本页事件及提示，导出对话和工具记录JSON | 不是完整M3审计或配送完成证明 |
| 交互与运行 | 抽屉收放、快捷键A、流式工具状态、停止接收、异常提示、本地草稿恢复 | 停止接收不保证取消已开始的工具或模型请求 |

## 启动 AERIS 调度助手

依赖安装完成后，从仓库根目录启动 AERIS 前端和助手服务。

```powershell
cd apps/console
npm.cmd run dev:all
```

打开 <http://127.0.0.1:5174/>，点击右下角“调度助手”或按A。也可以分开启动：

```powershell
npm.cmd run assistant
# 另开终端，同一目录：
npm.cmd run dev -- --port 5174 --strictPort
```

在新电脑安装：仓库根执行 `python -m venv .venv`，使用虚拟环境Python安装本目录 `requirements.txt`，然后在 `apps/console` 执行 `npm ci`。特殊Python路径可设置 `AERIS_PYTHON`。

## 建议演示顺序

先在助手里查询 ACK 语义并展开文档依据，核对 `accepted=true` 的含义。再问一个文档未涵盖的问题，核对缺少文档依据时的提示。

1. 问“查询当前飞行状态和电量”，展开工具结果，看来源；点击“定位无人机”。
2. 问“创建任务，从医疗物资中转站到北区应急中心”，助手追问载荷。继续“补充载荷1公斤，优先级P1”。
3. 在任务卡点击“预览几何路线”，等待真实A*计算，点击“地图展示预览”。改变终点会清除旧预览，避免错用。
4. 检查卡片后点击“确认保存草稿”，从任务空间查看。这里仅保存本地待确认任务，正式飞行参数仍缺。
5. 问“分析地形变化对当前航线的影响”。无变化时会如实提示，可点击“注入演示地形变化”，再“分析影响”。结果可能为未交叠，这是实际计算结果。
6. 需要展示“剩余航段交叠”时，可在地形设置导入同一坐标基准、覆盖未来航段的演示补丁，再分析；不能把不交叠案例改写成发现危险。
7. 问“总结本次任务记录”，点击底部导出，检查工具入出参、来源和DEMO标识。

### S2-01 的 R01 限制区

地图回放使用 S1-01，该场景没有限制区生效事件。要验证 R01 拦截，在「本地任务联调」选择并确认 S2-01。R01 在任务开始后 40 秒生效，独立校验发现基线路线进入已生效的 R01 后拦截任务。进入时刻以本次校验记录为准。保持该任务为选中状态，在助手里问「这单为什么被拦？」即可查看校验结果。[场景配置](../../eval/scenarios/v0.yaml)

## 怎样连接华为云模型

默认 `ASSISTANT_PROVIDER=local`：**本地规则驱动工具演示，未调用大模型，不能称为已联通的模型Agent。** 配置MaaS后会启用“模型选择工具 → 工具执行 → 模型读取结果选择下一步”的循环，最多4轮模型响应、8次工具调用。工具入出参单独展示，不展示隐藏思考内容。

需要由你在华为云账号里完成：

1. 在当前可用区域开通模型服务，选择明确支持工具/函数调用的模型。使用控制台提供的完整Chat Completions兼容地址、模型ID和API Key。本实现使用Bearer API Key；如果你的服务仅支持IAM Token或其他协议，需要再适配认证。
2. 复制本目录 `.env.example` 为 `.env`（根 `.gitignore` 已忽略），填写：

```dotenv
ASSISTANT_PROVIDER=maas
ASSISTANT_MAAS_ENDPOINT=控制台给出的完整HTTPS接口地址
ASSISTANT_MAAS_MODEL=控制台给出的模型ID
ASSISTANT_MAAS_API_KEY=你的APIKey
```

3. 重启本地助手后端。启动脚本会加载该文件；所有凭据只在Python服务端使用。浏览器不接收密钥，不使用 `VITE_` 变量。
4. 打开助手，连接栏应显示“模型接口 · 工具模式”。实际发送一次问题后，检查工具状态和回答来源；仅有健康检查不证明云端调用成功。
5. 如果模型不支持`tools`或返回格式不兼容，页面会报告错误，不会悄悄退回规则回答并冒充模型已连接。该路径已通过模拟模型测试，**尚无真实华为云凭据进行远端联调**。

没有购买、创建或使用你的云资源，也没有产生云端模型费用。这是MaaS兼容适配器，尚未接入AgentArts或Nexent平台；赛题2要求的AgentArts构建/编排/部署仍需单独完成。

## 接口和边界

- `GET /api/assistant/health`：协议、模式、配置状态、`dispatch_enabled=false`，不检查远端模型可用性，不返回密钥。
- `GET /api/assistant/places/search?q=城市与地址`：显式提交的 OSM / Nominatim 搜索，返回最多 5 个 WGS84 地点。公共服务有共享每秒一次限流、10 分钟缓存和 8 秒超时；不会按输入自动补全，也不会自动上传浏览器定位。该限流只适用于单进程本地服务，正式多用户部署需统一代理或自建地址检索服务，并核对公共服务使用政策。不可用时返回错误，使用地图或坐标选点继续操作。
- `POST /api/assistant/turn`：接收用户输入、最近对话、待确认草稿和当前演示上下文，返回NDJSON事件：`start/tool_start/tool_result/result/error/heartbeat`。
- 工具白名单包括 `search_project_docs`、`get_flight_status`、`get_task_status`、`list_events`、`list_places`、`update_task_draft`、`plan_task_preview`、`inspect_terrain_risk` 和 `get_capabilities`。文档索引首次查询时构建，修改索引内文档后重启助手服务即可更新。每条出处含文件路径、章节、原文行号和文件内容摘要。
- 模型不传完整地图或高程矩阵；由工具读取已登记场景并计算。任务草稿保存在浏览器，不替代公共 `core.models.Task`。
- 服务端在 `logs/assistant/YYYY-MM-DD_DEMO.jsonl` 留工具结果及回合编号，不记录API Key。日志不是防篡改审计；前端导出也不是原始飞控证据。
- 本服务绑定回环地址，限制Host/Origin、请求体和并发量，适合当前本地演示。上线前仍需用户身份、权限、任务归属、频率限制和持久化，不能直接暴露到公网。
- 实际M3接入点：用任务提案确认流程将完整参数转成公共Task，再调用TaskService；用M3审计读接口替换本页事件工具；由M3处理路线版本、校验、确认、命令与ACK。现有逻辑未被聊天模块替换。
- 模型对话的表达仍可能有误；地图/任务卡/工具证据显示实际结构化结果，正式安全结论必须由独立校验器产生。
