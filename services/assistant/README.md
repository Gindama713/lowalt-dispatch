# AERIS 调度助手：本地服务与华为云模型接入

前端位于 `apps/console/src/assistant/`，后端位于本目录。此服务支持独立控制台演示，保留现有 M2/M3/PX4 接口。

2026-11-11：同一服务现已挂载 `/api/dispatch/*` 本地合成任务链路。顶部「本地任务联调」可调用真实 M3/M2/独立校验及 M4 FakeExecutor，支持直连或 MQTT；操作见 [`services/api/README.md`](../api/README.md)。这与下面仅问答/草稿的助手工具是两个明确入口，不会把对话中的任务自动下发。

## 自然语言到真实地点工单（2026-11-28）

本地规则和模型入口都支持真实地点任务。先说“从江西农业大学到南昌航空大学，规划一条航线”或“江西农业大学和南昌航空大学之间规划一条路线”；没有日期也进入真实地点确认卡，不再错误调用仅支持虚拟站点的 ENU 预览。地点重名时选择候选，确认实际起降点、完整时间、载荷和优先级，再点击建单。未知值不猜测。

建单回复提供“打开地图并查看规划进展”入口。后台使用冻结的空域约束快照规划建筑与已知限制区避障路线；空域数据缺失保持未知。地图展示后，点击“综合检查任务”或问“综合检查当前工单的禁飞区、天气、风向和备降点”。`inspect_mission_plan` 只读取本次工单保存的路线和沿线预报，不以端点天气替代，也不会额外请求联网数据。环境矩阵、缺口清单和因素表共享这条实际路线；地图与保存路线不一致时拒绝复用证据。

风向、侧风和天气用于保存路线的事后环境评估及相应 ETA/能耗模型，不表示已完成风场感知的路径优化。没有核实的起降场点台账与标定能耗时，真实 WGS84 任务的备降可达及余量仍未判定；ENU 示例的冻结备降余量不能借用。页面保留本地规则/模型模式及保存证据的时间、来源，不把历史预报说成当前实测。

## 已实现什么

2026-11-25：新增 `get_task_evidence` 只读工具，输入“显示任务证据卡”或“显示拒绝案例的任务证据卡”。它与 `/demo` 共享 `apps/console/public/task-evidence.json`：S1-02 通过例、S1-01 拒绝例，展示路线、独立校验、余量曲线和缺口。数据来自冻结的示例参数算法运行，不是用户当前工单或实飞。重新生成：仓库根运行 `.venv/Scripts/python.exe apps/console/scripts/export_task_evidence.py`。算法和输入摘要变化时，助手会拒绝复用旧证据，需重新导出并重建前端。

知识库已登记 `AGENTS.md`、竞赛视频路线与演示整合状态。变更文档后重启助手，以更新关键词索引及 Chroma 语料指纹。

| --- | --- | --- |

## 启动 AERIS 调度助手

依赖安装完成后，从仓库根目录启动 AERIS 前端和助手服务。

```powershell
cd apps/console
npm.cmd run dev:all
```

打开 <http://127.0.0.1:5174/>，点击右下角“调度助手”或按A。也可以分开启动：

```powershell
npm.cmd run assistant
# 另开终端，同一目录：
npm.cmd run dev -- --port 5174 --strictPort
```

在新电脑安装：仓库根执行 `python -m venv .venv`，使用虚拟环境Python安装本目录 `requirements.txt`，然后在 `apps/console` 执行 `npm ci`。特殊Python路径可设置 `AERIS_PYTHON`。

## 建议演示顺序

先在助手里查询 ACK 语义并展开文档依据，核对 `accepted=true` 的含义。再问一个文档未涵盖的问题，核对缺少文档依据时的提示。

1. 问“查询当前飞行状态和电量”，展开工具结果，看来源；点击“定位无人机”。
2. 问“创建任务，从医疗物资中转站到北区应急中心”，助手追问载荷。继续“补充载荷1公斤，优先级P1”。
3. 在任务卡点击“预览几何路线”，等待真实A*计算，点击“地图展示预览”。改变终点会清除旧预览，避免错用。
4. 检查卡片后点击“确认保存草稿”，从任务空间查看。这里仅保存本地待确认任务，正式飞行参数仍缺。
5. 问“分析地形变化对当前航线的影响”。无变化时会如实提示，可点击“注入演示地形变化”，再“分析影响”。结果可能为未交叠，这是实际计算结果。
6. 需要展示“剩余航段交叠”时，可在地形设置导入同一坐标基准、覆盖未来航段的演示补丁，再分析；不能把不交叠案例改写成发现危险。
7. 问“总结本次任务记录”，点击底部导出，检查工具入出参、来源和DEMO标识。

### S2-01 的 R01 限制区

地图回放使用 S1-01，该场景没有限制区生效事件。要验证 R01 拦截，在「本地任务联调」选择并确认 S2-01。R01 在任务开始后 40 秒生效，独立校验发现基线路线进入已生效的 R01 后拦截任务。进入时刻以本次校验记录为准。保持该任务为选中状态，在助手里问「这单为什么被拦？」即可查看校验结果。[场景配置](../../eval/scenarios/v0.yaml)

## 怎样连接华为云模型

默认 `ASSISTANT_PROVIDER=local`：**本地规则驱动工具演示，未调用大模型，不能称为已联通的模型Agent。** 配置MaaS后会启用“模型选择工具 → 工具执行 → 模型读取结果选择下一步”的循环，最多5轮模型响应、8次工具调用，每轮最多5个顺序调用。工具入出参单独展示，不展示隐藏思考内容。

确认卡通过 `turn.confirmation` 提交完整年月日、UTC+8 时刻、起终点坐标、载荷、优先级与 `confirmation_id`。服务端直接使用用户确认的结构化字段建单。确认路径跳过模型解释，并用用户与确认标识进行幂等保存。相同确认重试返回原工单，确认内容改变须使用新的标识。旧工单文件继续可读。

工具执行会再次检查本轮权限。草稿修改后旧预览失效，天气证据按地点和目标时刻匹配，live 状态优先读取服务端遥测文件。知识检索在有关键词依据时直接返回，向量引用保留完整原文和对应行号。工单图表使用工具提供的数值，并标明最近工单的统计范围。

## 卡片、图表与交互式结果

助手响应通过 `presentation.version=1` 和 `presentation.blocks` 展示指标卡、统计图、数据表、事件时间线和路线小图。展示数据从工具结果构建，图表支持表格切换、排序与 CSV 导出，路线卡可关联到主地图。未知协议保留文字回答。

可直接问「用卡片展示当前电量和飞行状态」「做个工单看板」「用柱状图比较工单载荷」「用时间线展示最近事件」。任务草稿的「预览几何路线」会附带路线小图。

协议、代码位置与复用步骤见 [Agent 富界面输出与复用指南](../../docs/Agent富界面输出与复用指南.md)，跨语言适配可以使用 [JSON Schema](../../docs/agent-presentation.schema.json)。

需要由你在华为云账号里完成：

1. 在当前可用区域开通模型服务，选择明确支持工具/函数调用的模型。使用控制台提供的完整Chat Completions兼容地址、模型ID和API Key。本实现使用Bearer API Key；如果你的服务仅支持IAM Token或其他协议，需要再适配认证。
2. 复制本目录 `.env.example` 为 `.env`（根 `.gitignore` 已忽略），填写：

```dotenv
ASSISTANT_PROVIDER=maas
ASSISTANT_MAAS_ENDPOINT=控制台给出的完整HTTPS接口地址
ASSISTANT_MAAS_MODEL=控制台给出的模型ID
ASSISTANT_MAAS_API_KEY=你的APIKey
```

3. 重启本地助手后端。启动脚本会加载该文件；所有凭据只在Python服务端使用。浏览器不接收密钥，不使用 `VITE_` 变量。
4. 打开助手，连接栏应显示“模型接口 · 工具模式”。实际发送一次问题后，检查工具状态和回答来源；仅有健康检查不证明云端调用成功。
5. 如果模型不支持`tools`或返回格式不兼容，页面会报告错误，不会悄悄退回规则回答并冒充模型已连接。该路径已通过模拟模型测试，**尚无真实华为云凭据进行远端联调**。

没有购买、创建或使用你的云资源，也没有产生云端模型费用。这是MaaS兼容适配器，尚未接入AgentArts或Nexent平台；赛题2要求的AgentArts构建/编排/部署仍需单独完成。

## 接口和边界

- `GET /api/assistant/health`：协议、模式、配置状态、`dispatch_enabled=false`，不检查远端模型可用性，不返回密钥。
- `GET /api/assistant/places/search?q=城市与地址`：显式提交的 OSM / Nominatim 搜索，返回最多 5 个 WGS84 地点。公共服务有共享每秒一次限流、10 分钟缓存和 8 秒超时；不会按输入自动补全，也不会自动上传浏览器定位。该限流只适用于单进程本地服务，正式多用户部署需统一代理或自建地址检索服务，并核对公共服务使用政策。不可用时返回错误，使用地图或坐标选点继续操作。
- `POST /api/assistant/turn`：接收用户输入、最近对话、待确认草稿和当前演示上下文，返回NDJSON事件：`start/tool_start/tool_result/result/error/heartbeat`。
- 工具白名单包括 `search_project_docs`、`get_flight_status`、`get_task_status`、`list_events`、`list_places`、`update_task_draft`、`plan_task_preview`、`inspect_terrain_risk` 和 `get_capabilities`。文档索引首次查询时构建，修改索引内文档后重启助手服务即可更新。每条出处含文件路径、章节、原文行号和文件内容摘要。
- 模型不传完整地图或高程矩阵；由工具读取已登记场景并计算。任务草稿保存在浏览器，不替代公共 `core.models.Task`。
- 服务端在 `logs/assistant/YYYY-MM-DD_DEMO.jsonl` 留工具结果及回合编号，不记录API Key。日志不是防篡改审计；前端导出也不是原始飞控证据。
- 本服务绑定回环地址，限制Host/Origin、请求体和并发量，适合当前本地演示。上线前仍需用户身份、权限、任务归属、频率限制和持久化，不能直接暴露到公网。
- 实际M3接入点：用任务提案确认流程将完整参数转成公共Task，再调用TaskService；用M3审计读接口替换本页事件工具；由M3处理路线版本、校验、确认、命令与ACK。现有逻辑未被聊天模块替换。
- 模型对话的表达仍可能有误；地图/任务卡/工具证据显示实际结构化结果，正式安全结论必须由独立校验器产生。

## 大疆 FlySafe 厂商地理围栏

规划起终点或重算航线时，助手可按规划范围（端点外扩 800 m，这是查询边距，不是法定间隔）调用 PyPI 包 `dji-geo==0.1.0` 读取大疆 FlySafe / GEO 设备地理围栏，转成已有的 WGS84 约束快照，再走原来的逐航段冲突检查和绕行。界面、接口和助手文案都写明 **大疆 FlySafe 厂商地理围栏参考**。它不是法定空域，不是 UOM / 国家地图官网 / 天地图，也不是飞行批准。通过只表示「通过本次已知区域检查」。

查询失败或返回 0 个区域时，快照状态是 `unavailable`，不编造多边形，也不把空结果当成放行。起终点落在禁飞或法规限制参考区内会拒绝规划，不移动端点。地图上隐藏分类只影响显示。手动导入和演练走廊可以附加在成功的查询结果上，但不是主数据源。

`dji-geo` 需要 Python 3.12 及以上。助手 CI 使用 3.13；M3 工作流里的 Python 3.11 会跳过这一依赖，该进程把实时查询保持关闭而不是让整个安装失败。上游仓库 https://github.com/mochenya/dji-geo 在 2026-11-20 发布的 0.1.0 没有 LICENSE 文件，PyPI 轮子元数据也未声明许可证。本仓库只声明 PyPI 依赖，不拷贝其源码树。

实时查询默认开启。测试和浏览器回归设置 `AERIS_FLYSAFE_LIVE=0`，不会访问 `flysafe-api.dji.com`。手工核对时在已登录的本地助手上对一组真实起终点调用 `POST /api/assistant/airspace/flysafe`，核对返回里的 `reference_label`、`snapshot_id` 和 `source_status`。网络不可达时应看到 `unavailable` 和空的 `zones`，不能当成查询成功。

`assess_route_environment` 仍只做天气、障碍和缺口判定。虚拟场景的时变禁飞仍由规划器验收。FlySafe 快照不能代替这两条结论。

# 日间企业版的身份入口

当前本地 BFF 对任务、规划、遥测和助手业务接口要求登录，并对创建/执行操作校验角色。浏览器由首页和登录页建立 HttpOnly 会话；直接调用有副作用的接口还需 `X-Aeris-Request: 1`。首次管理员初始化、邀请注册、邮箱令牌本地交付、MFA及角色说明见 [前端日间企业版](../../docs/前端日间企业版.md)。独立规划API已挂载到 `/api/planning`，前端不需要另开8000端口。
