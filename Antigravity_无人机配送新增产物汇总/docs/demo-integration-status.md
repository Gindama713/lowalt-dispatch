## 演示入口

在 `apps/console` 安装锁定依赖（`npm ci`），启动 `npm run dev`，浏览器访问 `/demo`。首页也提供“观看竞赛演示”入口。不需要 Python 后端、账户、地图服务或云资源。生产部署应提供 SPA 路由回退。

确认示例工单后，播放三分钟情景。可以暂停、拖动时间轴、点击章节或已发生事件进行重拍。录制模式隐藏控制栏，Escape 恢复；重置后回到未确认状态。影片中的模型、地点、动画和状态均为演示素材，算法说明是概念示意，不是此次运行的规划结果。

## 虚构滨水城市视觉升级（2026-11-23）

- 视觉风格：蓝调微缩数字孪生，暖色窗灯、冷色玻璃、层次化地块与真实感道路纹理。
- 城市由固定的艺术布局生成 51 栋建筑，包含办公、住宅和仓储三类轮廓，以及河岸、公园、桥梁、街道路口、屋顶设施和绿化。
- 建筑与附属细节按材质批量实例化；固定灯光的阴影仅更新一次。无需额外在线贴图或地图服务。
- 摄影机通过已有回放时间轴选择视觉机位，暂停和跳章具有确定性。三维场景的建筑与位置均为虚构美术元素，未接入真实规划、坐标或飞控。
- 新增城市布局回归用例，以及浏览器中的城市资产加载断言。布局生成逻辑已检验为 51 栋可重复生成的多类建筑；本地工作环境未能启动完整构建与浏览器，改由独立 GitHub Actions 完成验收。回放测试、TypeScript/Vite 构建、Chromium 场景加载和交互测试均通过，并已生成实际渲染截图；性能帧率仍需在录屏机实测。上方测试结果属于先前整合版。

独立视觉验收工作流：[AERIS offline city visual](https://github.com/Gindama713/lowalt-dispatch/actions/workflows/demo-visual.yml)。无需启动 Python 服务，单独执行回放测试、前端构建、Chromium 浏览器断言和画面截图。原控制台工作流的后端格式检查与此验收独立。本次独立验收 [运行记录](https://github.com/Gindama713/lowalt-dispatch/actions/runs/45114946283) 通过，[截图产物](https://github.com/Gindama713/lowalt-dispatch/actions/runs/45114946283/artifacts/14790679743) 可供复查。

## 电影化城市与 CR30 特写（第二轮）

- 建筑维持同一虚构场景布局，增加倒角办公塔楼、金属立柱、玻璃幕墙、住宅阳台、仓库门头、太阳能板装饰、屋顶女儿墙和设备格栅。51 栋建筑与 8,747 个视觉实例归到 7 个实例化几何批次，仍使用离线素材。
- 城市增加一次生成的室内环境反射贴图、暖色主光、冷色轮廓光、静态阴影与渐变背景。河面通过本地着色器呈现随回放时间变化的艺术波纹及高光。
- 新增独立 CR30 产品展台，直接加载原有高精度 `cr30.glb`，使用独立三点布光及局部反射环境。城区仍显示 LOD 模型，产品展台只负责外观展示。
- 四种视觉模式：自动镜头（32–34 秒建筑近景、34–49 秒产品展台、49–52 秒建筑近景）、城市全景、建筑近景、CR30 特写。特写支持斜视、侧视、顶视；回放、任务字段和事件时间轴保持一致。录制模式隐藏额外控制区域。播放画面按 30 FPS 时间采样，暂停时仅在模型、视图、机位或窗口大小改变时重新绘制，城市与展台阴影按需更新。
- 验收增加自动切镜、手动视图、细节数量、离线高精度模型加载和特写截图。所有城市与模型坐标均为美术表现；未扩大实飞、实际规划或控制能力。

验收：第二轮预览分支的 Prettier 格式检查、4 项回放单元测试、TypeScript/Vite 生产构建和 Chromium 独立浏览器测试均通过。浏览器用时 22.3 秒，生成城市全景、建筑近景、CR30 斜视及顶视截图。录像机实际帧率仍需单独实测。
