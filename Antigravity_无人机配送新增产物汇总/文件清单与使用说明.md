# Antigravity 无人机配送项目（AERIS / lowalt-dispatch）新增与升级文件总览

本文件夹按照原仓库 `lowalt-dispatch` 的**1:1 相对目录结构**，完整汇总了在 Antigravity 中为本项目开发、修复和验证的全部 **53 个项目文件**（其中 **21 个全新创建文件**、**32 个集成与功能升级文件**），另附 `_预览截图与说明文档/`（实测渲染图与本地快捷脚本）。

> **直接覆盖到 Windows 电脑使用的快捷方法**：
> 将本文件夹除 `_预览截图与说明文档` 和本说明以外的目录（`apps`、`docs`、`planner`、`results`、`tests`、`start-windows.bat`、`事实文档.md`）直接复制覆盖到 Windows 电脑的 `lowalt-dispatch` 根目录：
> - **看电脑端 10× 深圳三维 + CR30 爆炸背景**：直接双击 `start-windows.bat`。
> - **在 DevEco Studio 看鸿蒙端 3D 爆炸背景**：在 DevEco Studio 中 `Open` 打开 `apps\harmony` 目录运行。
